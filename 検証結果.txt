Card Reveal Studio v0.13.0 検証結果

環境：Linux / Node.js 24 / FFmpeg 7.1.5 / Chromium (headless)

npm test：125件。
- 既存のカード・台形・外周強調、モデル検証、素材変形、透過／単色、90/120fps、実FFmpeg出力を確認。
- 保存・別名保存・グループ移動・破損／未知形式／容量不足時の保持、Undo/Redoと素材リソースの扱いを確認。
- 旧テロップ情報を含む保存データの読み込み互換性を確認。旧UIの登録・挿入機能を有効にする検証ではない。
- 新しいmedia-groups.test.jsでは旧データを上書きしない初期化、画像動画の独立性、名前の正規化、振り分けの保存、グループ削除時の移動、元ファイル参照と演出設定の保持、不正データの拒否を確認。

node tests/ui-smoke.cjs：現在のプラグイン・素材管理画面で検索、保存、ショートカット、保存前の確認、SABUの位置調整、グループ、別演出への適用、JSON、画像自動フィット、ネイティブAPIのキャンセル／失敗／再試行、幅1120/420/384pxを確認。

node tests/editing-ui-smoke.cjs：ドラッグ・キーボードの位置調整、Shift軸固定、取り消し・やり直し、blob保持、非同期フィット、保存状態、素材と配置の閉じる／保存／破棄、処理中の停止を確認。

node tests/channels-ui-smoke.cjs：
- 左端3カテゴリと、プラグイン内の元素材／作成済みの素材を確認。
- テロップの登録・挿入・試験モード・すべての保存のUIと起動スクリプトがないことを確認。
- 保存グループ、画像／動画の独立したグループの追加・振り分け・名前変更・削除・再読み込みを確認。
- 同名グループ、容量不足での保存失敗、別画面による振り分け変更を再現し、不意に上書きしないことを確認。
- PNG画像と実H264動画のプレビュー、非自動再生・ミュート・終了時の停止を確認。
- 素材を移動しても、保存済みの演出・素材と配置・旧テロップ登録情報が変わらないことを確認。
- 幅1120/760/420/384pxでメニューと素材一覧を操作し、横はみ出しがないことを確認。

node tests/file-drop-ui-smoke.cjs：
- Chromiumに実ファイルのドロップを送り、PNGとMP4の割り当て、指定したカードだけの差し替え、Undo/Redo、保存を確認。
- 一覧への混在した複数ファイルの登録、再読み込み、同一ファイルの再登録、配置の保持、プレビューへのドロップを確認。
- 非対応形式、1枚の枠への複数ファイル、パスを取得できない場合、登録先の削除、容量不足時に変更を確定しないことを確認。
- 選択中とは別のグループに対する右クリック、×による各段階の取消、Shift＋F10、狭い幅のメニュー、別画面の変更との競合を確認。
- File.pathとCEPのNode接続は模擬。ブラウザーのFileList、ドロップイベントと画像・動画デコードは実際のもの。

画面写真は、実際のパネルをサンプル素材で操作して撮影したもの。Premiere通信は模擬。
